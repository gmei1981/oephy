3模块详解

3.1 双核 LC VCO vco_x / vco_dual · netlist/inc/vco_dual.scs

系统位置：频率基准。输出 OUTP/OUTN 经 1kΩ 隔离电阻 + 两级反相缓冲送 MMD 计数； VCTRL 只接坦克变容管（本复现 KVCO≈0，见坑 1）。

结构：NMOS 交叉耦合负阻对（MN0/MN1，nf=16）+ 双电感上拉坦克（L0/L1 = 2.49nH, r=2， 8G 版 1.5nH）+ 固定电容组 CF0–CF11（cfmom_wo_p80，nr 参数为单元数）+ 连续变容管 CV0/CV1（moscap_rf wr=538n nfin=12，gate=OUTP/N、bulk=gnode=VCTRL）。双核包装 vco_dual： 核 B 经 MPWRB（PMOS，nf=64）供电开关 + MSWP/MSWN（nf=64）耦合开关，EN2=0.8 双核 / 0 单核。

// 核心负阻对与电感
MN1 (OUTP OUTN VSS VSS) nch_svt_mac l=16n nfin=2 w=58n nf=16 ...
L1 (VDD OUTN) inductor l=2.49n r=2
// 固定电容组（每通道标定 nr：主 195 / 近整数 172 / 8G 188）
CF6 (OUTP OUTN VSS) cfmom_wo_p80 ... nr=192 ...
// 连续变容管
CV0 (OUTP VCTRL VCTRL) moscap_rf wr=538n nfin=12 lr=200n gr=2 br=2 ...

指标：设计 6.2 G（Step 1）/ 8.0 G（Step 2）；实测 nr=192 时 6.161 G，8G 坦克 7.93 G； OUTP 摆幅 2.01 Vpp；PN −77.3/−77.2 dBc/Hz @100k@6G（单/双核几乎重合）。 实测调谐灵敏度：nr 每单元 −0.37 MHz（主通道）/ −0.97 MHz（近整数双核）/ −0.266 MHz（8G， 按 CKFB 口径）。

坑 1 · KVCO≈0 定案（5 批次穷举） moscap_rf 在 6 GHz 大摆幅下电容锁定在 Cmin 平台（C-V 台阶只有 ~0.2 V 宽，工作区 0.2–1.0 V 全在 Cmin），阶梯变容管组 / 晶体管变容管 / 偏置偏移全部试过均无可用调谐 → Plan A：零 KVCO 简化 + 按通道重调固定电容组（复现报告注③）。

3.2 10-bit RC DTC dtc_10b · netlist/inc/dtc_10b.scs

系统位置：参考路径延迟级。输入 CK2X（倍频后参考），输出 CKDTC 触发 SPD 斜坡； 1023 个码端口与解码器输出同名直连（无 vcvs 桥接，规避 Jacobian 奇异）。

结构：R0（rhim l=2.3µ w=2µ）+ 1023 个并联单元（NMOS 开关 Uk nf=2 + 单位电容 Ck=0.5fF，论文 Fig.11a 开关+真实电容结构）+ 输入反相（MNI/MPI）+ 复位管 MRST_D（nf=2）： CK_IN 低时 CKXB 高、VDLY 被钳到 VSS，防止放电期电容反灌电荷丢沿。

// unit: NMOS switch nf=2 + CLSB=0.5fF;  R0 rhim 2.3u x 2u
// paper: Tres = ln2*R*CLSB = 330 fs, full DR ~ 338 ps
R0 (CK_IN VDLY) rhim l=2.3e-06 w=2e-06
U1022 (VDLY CODE1022 UCAP1022 VSS) nch_svt_mac ... nf=2 ...
C1022 (UCAP1022 VSS) capacitor c=5e-16
MRST_D (VDLY CKXB VSS VSS) nch_svt_mac ... nf=2 ...  // 复位防反灌

指标：Tres = ln2·R·CLSB = 330 fs 设计；实测 337 fs ✓；满量程实测 290 ps （设计 ~345 ps，0.86× 由 KDTC LMS 吸收）；窗口内 INL 最差 ±1.3 ps ≈ ±4 LSB（含测量噪声）。 测试：16 码点扫描（sim/dtc/，scripts/dtc_meas.py）+ 链式验证（倍频→DTC 全码→SPD 斜坡 6.50ns/0.702V ✓）。

坑 2 · NMOS 变容管做单位电容不可用 1023 个关态栅电容垫底 ~1pF + C-V 非线性 → INL ±数十 ps；改为开关+真实电容后 INL 收敛。 另：无复位通路时电容反灌电荷在环路中丢沿（CKDTC 76.8M），加 CK2X 反相复位管解决。

3.3 SPD 斜坡采样鉴相器 spd_x · spd_cmp_gm.scs

系统位置：相位误差→电压转换。CK_SMP=CKFB 采样斜坡，CK_RST=CKRST（CKDTC 反相）复位， VHOLD 送比较器与 GM。

结构：二极管接法 PMOS MIR + RREF（rhim 38µ×450n）产生偏置 → MCS（nf=1）恒流给 CR0=30fF 充电 → 线性斜坡；MSMP（nf=8）源跟随采样（VHOLD = VRAMP − Vth,n）；MRST（nf=32） 强复位；CH（cfmom nr=12）保持电容。

MIR (VBSPD_M VBSPD_M VDD VDD) pch_svt_mac ... nf=1
RREF (VBSPD_M VSS) rhim l=38u w=450n
MCS (VRAMP VBSPD_M VDD VDD) pch_svt_mac ... nf=1
MSMP (VRAMP CK_SMP VHOLD VSS) nch_svt_mac ... nf=8   // 采样管
MRST (VRAMP CK_RST VSS VSS) nch_svt_mac ... nf=32   // 复位管
CH (VHOLD VSS VSS) cfmom_wo_p80 ... nr=12
CR0 (VRAMP VSS) capacitor c=30f

指标：斜坡 6.50 ns / 摆幅 0.702 V（VBSPD=0.48，153.6M 栅格；Step 2 10 ns 栅格 VBSPD=0.52）；采样窗 ~0.2–0.6 V 线性区；VHOLD 饱和上限 0.53 V（TB 实测）。

坑 3 · VBSPD 决定斜坡线性区 VBSPD=0.20 时斜坡 0.3 ns 即饱和（相位信息丢失）→ 0.48 线性化。采样落斜坡底部平台段 = 鉴相器增益≈0（v13 死态根因之一）。

3.4 比较器 cmp_x · spd_cmp_gm.scs

系统位置：VHOLD vs VREF 判决 → EBIT=e[k]，同时驱动 LMS 与失调 DSM 反馈。

结构：五管差分对（MN1/MN2 nf=2，二极管负载 MP1/MP2 nf=2，尾电流 MTAIL nf=2， VBIAS=VBCMP=0.8 V）+ 输出反相级（MN3/MP3 nf=2）。

指标：数字判决输出 EBIT（0/0.8 V）；共模工作区按 VREF 0.1–0.3 V 设计。

坑 4 · CM0.05 动态不翻转 尾电流管在低共模下亚阈值冻结（gm 17 pS 量级），比较器动态失效 —— v13 死态共犯；健康区 VHOLD≥0.1 V（TB 佐证）。

3.5 GM + CI 积分路径 gm_x · spd_cmp_gm.scs

系统位置：Type-II 环积分路径。I_OUT 给顶层 CI（2pF，ic=0.55V）充放电形成 VCTRL_I。

结构：NMOS 差分对（MN1/MN2 nf=1，输入 VHOLD/VREF）+ 尾电流（nf=1）+ PMOS 镜像 （MP1 二极管 / MP2 l=72n 拉长 4.5× 弱上拉，v2 修复：上拉 8.4nA→1.9nA 与下拉对称）。

指标：设计 0.5 µS / CI=15pF@500kHz（论文口径）；本复现 gm 17 pS@CM0.05 实测、 CI=2p（复用+调参，环路 BW 由 VHF 比例路径主导）。

3.6 MMD + SEL + MASH1-1 DSM pll_mmd_edge.va

系统位置：VCO 输出 → CKFB 分频 + SEL 半周期抖动 + ε 序列（K_DTC 校准相关量）。 晶体管缓冲链（两级反相 nf=4 + 1kΩ 隔离）后的 MMDIN 进 VA。

结构：对 vco_in 上升/下降沿双沿事件计数；cnt_target = floor((Nint2+y)/2)； SEL=+1 时挂起半个 VCO 周期（CKFB2 下降沿重定时），SEL=−1 时上升沿触发 —— 每分频只出 一个 CKFB 沿。MASH1-1：x1/x2/c2p 三个累加器，y = c1+c2−c2p；ε（epsc）= 2(target_cyc − ncyc·(Nint2+frac2)/2) + (0.5−frac2)；alt 奇偶周期交替供 CKREF DCC 相关。

// SEL=+1: 上升沿挂起, 下降沿触发 (半周期延迟 = 量化步长 TVCO/2)
@(cross(V(vco_in) - vth, +1)) begin
    cnt = cnt + 1;
    if (cnt >= cnt_target && half_pending == 0) begin
        if (sel_v > 0.0) begin half_pending = 1; end
        else begin ... ckfb_v = 1.0 - ckfb_v; end
    end
end

指标：Step 1 Nint2=40/frac2=0.364583（主通道）、42/0.000651（近整数）→ CKFB=153.6M； Step 2 Nint2=80/frac2=0 → CKFB=100M。实例 vth=0.7（顶层覆盖 VA 默认 0.4）。 实测：三通道 CKFB 全程恒定（fire rate 无丢沿）。

坑 5 · 旧版 SEL=+1 双沿触发 每分频出两个沿 → SPD 参考网格被污染、有效分频比 83.6（预期 80.73）的根因；改为 「SEL=+1 挂起等下降沿」后每分频严格一个沿。

3.7 3×sign-LMS + 失调 DSM pll_lms.va

系统位置：后台校准大脑。输入 EBIT/SEL/ALT/EPSC，输出 KDTC（1V=1）、VDCC/RDCC （1V=1ps）给解码器，VREF 回比较器参考。

结构：固定周期 timer(1/fref)（采样沿后 0.3ns）每参考周期更新一次； 四路并行：kdtc += mu_k·sgn·sign(epsc)、vdcc += mu_v·sgn·sel、rdcc += mu_r·sgn·alt、 ohat += mu_off·sgn（vref = vref0 + (ohat−offset_s)·m_slope 负反馈）。限幅：KDTC 0.5–1.5、 VDCC/RDCC ±500 ps、ohat ±200 ps。mode=1 分相自举窗口（0.4/2.3/3.9/5.5 ms × tscale=1e-6）。 顶层实例：mu_k=0.01、mu_v=5e-13、mu_r=1e-13、mu_off=4.2e-13、K0=1.0、vref0=0.15、 m_slope=1e9；Step 2 禁用 mu_k=mu_v=0。

@(timer(t_samp, 1.0/fref)) begin
    sgn = (V(ebit) > vth) ? 1 : -1;
    ohat_s = ohat_s + mu_off*sgn;
    vdcc_s = vdcc_s + mu_v*sgn*V(sel);
    rdcc_s = rdcc_s + mu_r*sgn*V(alt);
    kdtc_s = kdtc_s + mu_k*sgn*((V(epsc)>0.0)?1.0:...);
end
// vdcc/rdcc 输出 1V=1ps;  vref 负反馈闭环

实测：四路全部活动；本工作点无干净收敛（RDCC 慢漂 −14→−95@8µs 仍走、VDCC ±80 大摆幅、KDTC 0.5–1.4 抖振）——零 KVCO 结构性原因（复现报告注②）。

坑 6 · 更新时钟与标度 ① 旧版用 CKFB 双向沿 = 每周期更新 2 次且 ebit/clk 同沿事件序歧义 → 固定周期 timer； ② vref 旧标度 1e9 与 m_slope=33mV/ps 不一致 → 改 (ohat−offset)·m_slope 与 MATLAB 1:1。

3.8 倍频器与 LMS 时钟 pll_hybrid_aux.va

系统位置：参考路径前端。pll_doubler_edge 把 76.8M 参考倍频为 153.6M（CKDTC 栅格）； Step 2 用顶层 Edbl vcvs 直通（100M 不经倍频）。pll_clk_lms 生成 LMS 更新时钟（CKFB 沿后 300ps）。

结构：XOR 定时器型——REF 每个沿（升+降）输出高、thalf=3.25ns 后回落 → 153.6M、 50% 占空比。

坑 7 · 每沿翻转版是延迟复制 旧版每个 REF 沿翻转输出 → 只是 76.8M 延迟复制（斜坡周期 13ns、撞 0.8V 轨、采样网格错相 → 死环）。 定时器型 XOR 修复。

3.9 DTC 温度计解码器 pll_dtc_decoder_10b.va

系统位置：相位误差 → 1023 温度计码。输入 EPSC（ε，TVCO 单位）、SEL、ALT 与 LMS 输出， 1023 个输出与 DTC 码端口同名直连。

结构：延迟计算 tdel = K_DTC·(epsc − (0.5 − frac2))·(0.5/fout)（秒）， code = round(tdel/Tres)，温度计 = code + 511（0..1022 有效，511 为 DTC 中点）， 输出加 transition(50p) 平滑。参数 fout/fref/frac2/Tres 按通道传入。

坑 8 · 三个实现细节 ① 1023 端口单行 ≈6.5KB 解析失败 → 每 16 端口折行；② 解码输出与 DTC 码端口同名直连、 删除 vcvs 桥接（Jacobian 零对角奇异）；③ transition(50p) 消除 LTE 松弛 5-10× 拖慢。

3.10 顶层集成 gen_top.py 生成

互联要点：

  • VCO 输出缓冲链：OUTP →Rbuf 1k→ BUFFIN → 两级反相（nf=4）→ NBUF1 → MMDIN； 8G 全速翻转验证 ✓（2.01 Vpp 摆幅健康）
  • 预充电启动：Iinj 0–2ns −550µA → VI≈0.55 V，环路从近锁定态启动（VCTRL=0 时 VCO 低频、采样相位冻结在复位区 → 谐波锁死，无外力无法捕获）
  • VCTRL 求和：比例路径 VHOLD →Rf 5k/Cf 5p→ VHF →Ep 0.06×→ VN1；VCTRL = VI + VN1
  • 复位链：Einv（CKRSTI=−CKDTC）+ Esumrst（CKRST = 0.8 + CKRSTI）
  • tran 配置：maxstep=2p、gear2only、ic=OUTP=0.6；标定跑 strobe 100p， 精采样跑无 strobe 只存 OUTP/CKFB/VCTRL
